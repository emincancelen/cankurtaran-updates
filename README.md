# Cankurtaran Updates

Bu depo Cankurtaran masaüstü uygulamasının otomatik güncelleme dağıtımı için kullanılır.

Kaynak kod burada tutulmaz. Yeni sürümler **Releases** bölümünde yayınlanır ve Cankurtaran uygulaması `electron-updater` ile bu sürümleri otomatik olarak kontrol eder.

Her release için beklenen dosyalar:

- `Cankurtaran-Setup-x.y.z.exe`
- `Cankurtaran-Setup-x.y.z.exe.blockmap`
- `latest.yml`

Sürüm etiketi uygulama sürümüyle aynı olmalıdır. Örnek: `v0.3.5`.
